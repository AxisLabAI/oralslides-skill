# OralSlides Local Skill

Turn a PowerPoint or PDF deck into a narrated MP4 on your own computer. Your AI
client writes the narration, `edge-tts` generates speech, and FFmpeg creates the
video. No OralSlides account or hosted API is required.

## Install

Install LibreOffice, Poppler and FFmpeg, then install the Python requirements:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r oralslides-local/requirements.txt
python oralslides-local/scripts/oralslides.py doctor
```

Copy `oralslides-local` into your client's skill directory. Codex uses
`~/.codex/skills/`; Claude Code uses `.claude/skills/`; Cursor uses
`.cursor/skills/`.

## Manual workflow

```bash
python oralslides-local/scripts/oralslides.py prepare deck.pptx --output work
# Fill work/scripts.json with narration for every slide.
python oralslides-local/scripts/oralslides.py tts work
python oralslides-local/scripts/oralslides.py compose work --output presentation.mp4
```

Edge TTS is an online speech service. Slide rendering and video composition stay
on the local machine, while narration text is sent to Microsoft's Edge TTS
service. See `scripts.json` generated by `prepare` for the required schema.
